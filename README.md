# Budapest Social Compass

A standalone Google Maps web app for exploring Budapest social-scene heat, universities, student accommodation, student hangouts, and optional stay/sleep planning.

Open `index.html` directly in a browser, or run a small static server:

```sh
python3 -m http.server 5191
```

The heat layers are heuristic travel-planning signals, not official crime,
homelessness, attractiveness, or public-safety statistics.
